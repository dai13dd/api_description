ノーコード開発者のための超入門

Web APIってなに？

アプリの裏側で、面倒な処理をまとめて代行してくれる
「専用の窓口」 です

難しい専門用語は覚えなくてOK！

レストランの「店員さん」をイメージしてください。お客さん（アプリ）が「これください」とお願いするだけで、裏側のキッチン（データベース）から必要なデータを用意して運んできてくれる存在です。

02 / Why Web API?

もしPower Appsだけで全部やろうとすると…

データベースへの直接接続や複雑なデータ処理をアプリ側だけで組むと、3つの壁にぶつかります。

課題 01

設定が複雑になる

データの接続・検索・エラー処理などをノーコードの数式だけで組もうとすると、設定がどんどん複雑になり、本来の「画面づくり」に集中できなくなります。

課題 02

アプリが重くなる

大量のデータをアプリ側に読み込んでから集計・加工しようとすると、スマホやPC側への負荷が増え、画面の切り替えや動作が遅くなってしまいます。

課題 03

使い回せない

別の部署向けアプリやExcelツールで「同じデータ」が欲しくなったとき、アプリの中に処理が埋め込まれていると、また一から作り直す羽目になります。

だからこそ、「画面」と「裏側の複雑な処理」を分ける Web API が活躍します！

04 / Benefits

Web APIを使うと何が嬉しいの？

複雑な処理をWeb APIに任せることで、ノーコード開発の良さを最大限に活かせます。

メリット 01

開発がラク

難しいデータベース処理やプログラムを書かず、パーツ（API）を1つ呼ぶだけで完了。画面のデザインや使い勝手の改善に集中できます。

メリット 02

使い回せる

一度Web APIを用意しておけば、別のPower AppsやExcelなどからも同じAPIを呼ぶだけで再利用できます。同じ処理の作り直しが不要になります。

メリット 03

安全

データベースのパスワードや接続情報などをアプリ側に直接持たなくて済むため、情報漏えいや誤操作のリスクを減らせます。
